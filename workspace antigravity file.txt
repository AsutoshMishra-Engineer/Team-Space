## What YOU Need to Do (Step by Step)

### Step 1: Install Node.js (one time)
1. Go to [nodejs.org](https://nodejs.org)
2. Download the **LTS** version (the big green button)
3. Run the installer — click "Next" on everything, all defaults are fine
4. When done, open a terminal (PowerShell) and type: `node --version`
5. If you see a number like `v20.x.x`, you're good

### Step 2: Create Supabase Project (one time)
1. Go to [supabase.com](https://supabase.com) and sign up (free)
2. Click **"New Project"**
3. Pick any name (like "team-workspace")
4. Set a **database password** (save it somewhere safe — you won't need it in the code, but don't lose it)
5. Pick the region closest to you
6. Wait ~2 minutes for it to create

### Step 3: Copy 2 Values (one time)
1. In your Supabase dashboard, go to **Settings → API**
2. Copy the **Project URL** — looks like `https://xxxxx.supabase.co`
3. Copy the **anon/public key** — a long string starting with `eyJ...`
4. Paste both into the `.env` file I'll create for you (I'll show you exactly where)

### Step 4: Run SQL Script (one time)
1. In Supabase dashboard, go to **SQL Editor**
2. Click **"New Query"**
3. Paste the entire SQL file I'll give you
4. Click **"Run"**
5. You should see "Success" — that's it!

### Step 5: Configure Supabase Auth Settings (one time)
1. In Supabase dashboard, go to **Authentication → URL Configuration**
2. Set **Site URL** to `http://localhost:5173`
3. Add `http://localhost:5173/**` to **Redirect URLs**
4. Go to **Authentication → Providers → Email**
5. Make sure "Enable Email Provider" is ON
6. Make sure "Confirm email" is ON

### Step 6: Run the Website (every time you want to work on it)
1. Open PowerShell in the project folder
2. Type: `npm install` (first time only)
3. Type: `npm run dev`
4. Open the URL shown in the terminal (usually `http://localhost:5173`)

### Step 7: Deploy to Vercel (one time, when ready)
1. Push code to GitHub (I'll help you with this)
2. Go to [vercel.com](https://vercel.com), sign in with GitHub
3. Click "Import Project", pick your repo
4. Add the 2 environment variables (URL + Key)
5. Click Deploy — done! You get a live URL

## Database Schema (6 Tables)

| Table | Purpose |
|-------|---------|
| `profiles` | User profiles with custom User ID (`NNNLLNN` format) |
| `teams` | Team records with auto-generated Team Code (`NNNLL` format) |
| `team_members` | Who belongs to which team, their role and status |
| `announcements` | Team announcements with optional deadlines |
| `chat_messages` | Team chat messages |
| `team_files` | File metadata (actual files in Supabase Storage) |

Auto-generated via database triggers:
- **User ID** (`304TX58`) — created when email is verified
- **Team Code** (`582QK`) — created when a team is created
